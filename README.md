# SabtBrooker — سامانه کارگزاری هوشمند ماده ۱۰

پلتفرم کارگزاری رسمی سازمان ثبت اسناد و املاک کشور جهت اجرای «قانون الزام به ثبت رسمی معاملات اموال غیرمنقول». این سامانه زنجیره کامل خدمات ثبتی از نقشه‌برداری تا صدور گواهی نهایی را به صورت هوشمند مدیریت می‌کند.

## 🚀 وضعیت پروژه (Current Status)

- **Backend (Go):** ۱۰۰٪ کامل — امن، پایدار و تست شده (تیر ۱۴۰۵).
- **Web Frontend (Next.js):** ۱۰۰٪ کامل — نسخه PWA با قابلیت نصب روی موبایل و دسکتاپ.
- **Mobile App (Flutter):** ۸۰٪ کامل — قابلیت‌های آفلاین و Geo-tagging آماده بیلد نهایی.
- **Security:** ۱۰۰٪ کامل — تمام لایه‌های Auth, Payment, Injection و Storage ممیزی و مقاوم‌سازی شدند.
- **CI/CD:** عملیاتی — خط لوله استقرار و تست‌های خودکار فعال است.

## 🛠 پشته فنی (Full Stack)

| لایه | تکنولوژی | توضیحات |
|---|---|---|
| **Backend** | Go 1.23 (Echo) | معماری Clean + امنیت لایه‌بندی شده + PostGIS |
| **Frontend** | Next.js 15 (React 19) | کامپوننت‌های مدرن + پشتیبانی PWA |
| **Mobile** | Flutter | مدیریت وضعیت BLoC + متادیتا جغرافیایی (EXIF) |
| **Infrastructure** | NATS + Redis + MinIO | زیرساخت مقیاس‌پذیر و پیام‌محور |

## 🔐 قابلیت‌های امنیتی تثبیت شده (۱۰۰٪)

- **امنیت فایل**: محدودیت شدید فرمت‌های آپلود و استفاده اجباری از **S3 Pre-signed URLs**.
- **ضد Brute-force**: سیستم هوشمند Rate-limiting روی OTP و احراز هویت.
- **محافظت IDOR**: کنترل دسترسی (Access Control) دقیق در تمام لایه‌های پرونده و مالی.
- **امنیت دیتابیس**: مقاوم‌سازی ۱۰۰٪ در برابر حملات SQL Injection.
- **اعتبار‌سنجی Geo-tag**: تایید اصالت تصاویر میدانی بر اساس مختصات واقعی GPS.

## 🔗 پیش‌نیازهای اتصال به سامانه‌های ملی

۱. **مستندات GSB**: جهت احراز هویت شاهکار و ثنا.
۲. **فرمت سامانه مانا**: جهت ارسال نقشه‌های فنی.
۳. **دستورالعمل ماده ۱۱۴**: جهت تطبیق نهایی تعرفه‌ها.

## 🚦 دستور اجرای سریع

```bash

cd backend && go run cmd/server/main.go
cd frontend && npm run dev
```
