# SabtBrooker — سامانه کارگزاری هوشمند ماده ۱۰

پلتفرم کارگزاری رسمی سازمان ثبت اسناد و املاک کشور جهت اجرای «قانون الزام به ثبت رسمی معاملات اموال غیرمنقول». این سامانه زنجیره کامل خدمات ثبتی از نقشه‌برداری تا صدور گواهی نهایی را به صورت هوشمند مدیریت می‌کند.

## 🚀 وضعیت پروژه (Current Status)

- **Backend (Go):** ۱۰۰٪ کامل — شامل Auth, Case Management, Workflows, PostGIS, Zarinpal, SMS.
- **Web Frontend (Next.js):** ۱۰۰٪ کامل (PWA Enabled) — ویزاردهای هوشمند، نصب‌پذیر روی اندروید و iOS.
- **Mobile App (Flutter):** ۸۰٪ کامل — قابلیت Geo-tagging، سینک آفلاین و بازدید میدانی.
- **Security:** در حال ممیزی (۸۰٪) — ممیزی IDOR، امنیت پرداخت و پیشگیری از SQL Injection تکمیل شد (تیر ۱۴۰۵).
- **CI/CD:** عملیاتی — تمام تست‌ها و بیلدهای بک‌اِند و فرانت‌اِند سبز هستند.

## 🛠 پشته فنی (Full Stack)

| لایه | تکنولوژی | توضیحات |
|---|---|---|
| **Backend** | Go 1.23 (Echo) | معماری تمیز (Clean Architecture) + امنیت لایه‌بندی شده |
| **Frontend** | Next.js 15 (React 19) | پشتیبانی کامل از PWA، ویزاردهای داینامیک |
| **Mobile** | Flutter | مدیریت وضعیت (BLoC), دوربین، GPS، متادیتا EXIF |
| **Database** | PostgreSQL 16 + PostGIS | عملیات مکان‌محور و ذخیره نقشه‌های فنی |
| **File Storage** | MinIO (S3) | مدیریت امن اسناد با Presigned URLs |
| **Infrastructure** | NATS + Redis | سیستم Event-driven و کشینگ استعلام‌ها |

## 🔐 قابلیت‌های امنیتی تثبیت شده

- **محافظت IDOR**: کنترل دقیق دسترسی به پرونده‌ها و تراکنش‌های مالی بر اساس مالکیت و نقش.
- **امنیت پرداخت**: محاسبه مبلغ تراکنش صرفاً در سمت سرور و وریفای دوجانبه با درگاه زرین‌پال.
- **احراز هویت OTP**: اتصال به پنل SMS و Rate-limiting درخواست‌ها.
- **اعتبار‌سنجی Geo-tag**: استخراج و تطبیق متادیتای GPS عکس‌ها با موقعیت ملک.

## 🔗 پیش‌نیازهای اتصال به سامانه‌های ملی

۱. **مستندات GSB**: جهت احراز هویت شاهکار و ثنا.
۲. **فرمت سامانه مانا**: جهت ارسال نقشه‌های فنی.
۳. **دستورالعمل ماده ۱۱۴**: جهت تطبیق نهایی تعرفه‌ها.

## 🚦 دستور اجرای سریع

```bash
docker-compose up -d
cd backend && go run cmd/server/main.go
cd frontend && npm run dev
```
