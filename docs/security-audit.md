# SabtBrooker — چک‌لیست ممیزی امنیتی و تست نفوذ

این سند برای پیگیری وضعیت امنیت لایه‌های مختلف سامانه کارگزاری ایجاد شده است.

## ۱. لایه API (Backend)
- [x] **احراز هویت (Auth)**:
    - [x] تست Brute-force روی ارسال OTP -> **امن** (Rate-limiting فعال).
    - [x] بررسی انقضای صحیح Access Token و Refresh Token -> **تایید شد**.
    - [x] تست JWT Rotation و اطمینان از ابطال توکن‌های قبلی -> **تایید شد**.
- [x] **دسترسی (Authorization)**:
    - [x] تست IDOR روی پرونده‌ها -> **اصلاح شد**.
    - [x] تست IDOR روی شروع پرداخت -> **اصلاح شد**.
    - [x] تست RBAC -> **امن** (دسترسی کارشناس/متقاضی کاملاً ایزوله است).

## ۲. لایه پرداخت (Payment)
- [x] **دستکاری مبلغ** -> **امن**.
- [x] **تایید تراکنش** -> **امن**.
- [x] **Callback Security** -> **امن** (Server-side validation).

## ۳. امنیت فایل و ذخیره‌سازی
- [x] **Pre-signed URL** -> **تایید شد** (تمام دسترسی‌ها موقتی است).
- [x] **محدودیت فرمت آپلود** -> **اصلاح شد در تیر ۱۴۰۵** (افزودن Allow-list پسوندها در StorageHandler).

## ۴. یافته‌های جاری
- **VULN-001 (High)**: IDOR در پرونده‌ها -> **رفع شد**.
- **VULN-002 (Medium)**: IDOR در پرداخت -> **رفع شد**.
- **VULN-003 (Low)**: تایید مجدد تراکنش -> **رفع شد**.
- **VULN-004 (Medium)**: SQL Injection پتانسیل -> **رفع شد**.
- **VULN-005 (Medium)**: آپلود فایل‌های غیرمجاز -> **رفع شد** (اعمال محدودیت Content-Type).
