این سند برای پیگیری وضعیت امنیت لایه‌های مختلف سامانه کارگزاری ایجاد شده است.

## ۱. لایه API (Backend)
- [x] **اعتبارسنجی ورودی**:

## ۴. یافته‌های جاری
- **VULN-001 (High)**: آسیب‌پذیری IDOR در هندلر پرونده‌ها.
    - **وضعیت**: رفع شد.
- **VULN-002 (Medium)**: آسیب‌پذیری IDOR در ایجاد لینک پرداخت.
    - **وضعیت**: رفع شد.
- **VULN-003 (Low)**: امکان تلاش مجدد برای وریفای تراکنش‌های موفق.
    - **وضعیت**: رفع شد.
- **VULN-004 (Medium)**: پتانسیل SQL Injection در نام ستون‌های کوئری‌های داینامیک.
