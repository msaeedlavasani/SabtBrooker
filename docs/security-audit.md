# SabtBrooker — چک‌لیست ممیزی امنیتی و تست نفوذ

این سند برای پیگیری وضعیت امنیت لایه‌های مختلف سامانه کارگزاری ایجاد شده است.

## ۱. لایه API (Backend)
- [ ] **احراز هویت (Auth)**:
    - [ ] تست Brute-force روی ارسال OTP.
    - [ ] بررسی انقضای صحیح Access Token و Refresh Token.
    - [ ] تست JWT Rotation و اطمینان از ابطال توکن‌های قبلی.
- [ ] **دسترسی (Authorization)**:
    - [ ] تست IDOR روی پرونده‌ها (آیا کاربر A می‌تواند پرونده کاربر B را ببیند؟).
    - [ ] تست RBAC (آیا نقش کارشناس می‌تواند به تنظیمات ادمین دسترسی داشته باشد؟).
- [ ] **اعتبارسنجی ورودی**:
    - [ ] تست SQL Injection روی تمام فیلترهای جستجو.
    - [ ] تست XSS در فیلدهای متنی (آدرس، توضیحات ادعا).
    - [ ] تست آپلود فایل (آیا می‌توان اسکریپت‌های اجرایی به جای PDF آپلود کرد؟).

## ۲. لایه پرداخت (Payment)
- [ ] **دستکاری مبلغ**: آیا می‌توان با تغییر پارامترهای ارسالی به درگاه، مبلغ را صفر کرد؟
- [ ] **تایید تراکنش**: بررسی صحت منطق `VerifyPayment` (اطمینان از عدم پذیرش تراکنش‌های تکراری یا فیک).
- [ ] **Callback Security**: اطمینان از اینکه فقط IPهای PSP مجاز به فراخوانی Callback هستند.

## ۳. لایه موبایل
- [ ] **ذخیره‌سازی محلی**: بررسی اینکه اطلاعات حساس در `shared_preferences` یا دیتابیس محلی رمزنگاری شده باشند.
- [ ] **SSL Pinning**: (اختیاری) جلوگیری از حملات Man-in-the-Middle.
