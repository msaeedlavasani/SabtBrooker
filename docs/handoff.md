> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۲۹ (تکمیل پنل کارشناس و رفع خطاهای کامپایل)  
> فاز فعلی: Phase 2 — پیاده‌سازی Frontend (۹۰٪)  
> پیشرفت کلی: ~۹۰٪

---

## ۱. خلاصه اقدامات انجام شده (پنل کارشناس و پایداری)

در این مرحله، تمامی بخش‌های مربوط به «سرویس نقشه» و زیرساخت‌های کارشناسی نهایی شد:

### ✅ بک‌اِند (Backend)
- **رفع خطای Type Mismatch**: مشکل تبدیل `string` به `uuid.UUID` در متد `Accept` کارشناس برطرف شد.
- **تخصیص کارشناس**: متد `AssignExpert` با موفقیت در لایه‌های Repository و Service پیاده‌سازی و تست شد.
- **تغییر پورت**: بک‌اِند روی پورت **8081** تثبیت شد تا با سرویس‌های مک تداخلی نداشته باشد.
- **Storage**: قابلیت صدور Presigned URL برای آپلود مستقیم به MinIO کاملاً فعال است.

### ✅ فرانت‌اِند (Frontend)
- **پنل عملیاتی کارشناس**: 
    - داشبورد اختصاصی (`/expert/dashboard`) برای مشاهده پرونده‌های منتظر تخصیص.
    - صفحه جزئیات کارشناسی (`/expert/cases/[id]`) برای مدیریت چرخه نقشه.
- **آپلود مدارک**: کامپوننت `FileUpload` متصل به MinIO در فرم‌های کارشناسی و متقاضی ادغام شد.
- **مدیریت وضعیت**: نمایش زنده مراحل (تخصیص کارشناس، بازدید میدانی، تایید نهایی) در UI.

---

## ۲. ساختار مسیرهای نهایی (Frontend)
- `/`: ورود (OTP)
- `/dashboard`: پنل متقاضی (تشکیل پرونده و مشاهده وضعیت)
- `/expert/dashboard`: داشبورد کارشناس (پذیرش پرونده)
- `/expert/cases/[id]`: پنل تایید نقشه و بارگذاری مدارک فنی

## ۴. دستور اجرای سریع
```bash
docker-compose up -d
cd backend && go run cmd/server/main.go # Port 8081
cd frontend && npm run dev             # Port 3000
```
