# SabtBrooker — سند تحویل پروژه (Handoff)

> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۳۰ (پیاده‌سازی Geo-tagging و رابط کاربری بازدید میدانی در موبایل)  
> فاز فعلی: Phase 4 — اپلیکیشن موبایل نقشه‌بردار (۴۰٪)  
> پیشرفت کلی: عملیاتی کامل در وب و هسته (۱۰۰٪) | موبایل در جریان

---

## ۱. خلاصه اقدامات انجام شده

در این مرحله، قابلیت‌های کلیدی اپلیکیشن نقشه‌بردار پیاده‌سازی شد:

### ✅ اپلیکیشن موبایل (Mobile)
- **Geo-tagging هوشمند**: 
    - پیاده‌سازی `LocationService` برای مدیریت دسترسی‌های GPS و دریافت مختصات دقیق در لحظه.
- **رابط کاربری بازدید میدانی**:
    - ایجاد `SurveyDetailScreen` با قابلیت ثبت عکس‌های چهار جهت اصلی ملک (شمال، جنوب، شرق، غرب).
    - نمایش خودکار مختصات GPS روی هر اسلات عکس بلافاصله پس از ثبت.
- **ناوبری (Navigation)**: اتصال لیست پرونده‌ها به صفحه جزئیات بازدید جهت شروع فرآیند کارشناسی.
- **یکپارچگی بصری**: استفاده از تم رنگی سرمه‌ای و طلایی مطابق با نسخه وب.

### ✅ سیستم‌های زیرساختی
- تمامی کدهای بک‌اِند، وب و دیتابیس در وضعیت پایدار (Stable) و تست شده قرار دارند.
- حذف فایل‌های آرشیو زائد جهت بهینه‌سازی مخزن.

---

## ۲. وضعیت نهایی فرآیندها (عملیاتی)
1. **وب/بک‌اِند**: کامل (هویت، نقشه، ادعا، گواهی، پرداخت).
2. **موبایل**: قابلیت عکس‌برداری Geo-tagged فعال است. گام بعدی: ذخیره‌سازی آفلاین.

---

## ۳. تسک‌های باقی‌مانده

| اولویت | کار | توضیح |
|---|---|---|
| 🔴 ۱ | **آفلاین مود (Local DB)** | پیاده‌سازی `sqflite` جهت ذخیره بازدیدها در صورت عدم دسترسی به اینترنت |
| 🟡 ۲ | **سینک خودکار** | ارسال اطلاعات ذخیره شده به بک‌اِند پس از برقراری اتصال |
| 🟢 ۳ | **تست نفوذ** | ممیزی نهایی امنیت APIها |

---

## ۴. دستور اجرای سریع
```bash
# بک‌اِند (Port 8081)
cd backend && go run cmd/server/main.go

# فرانت‌اِند وب (Port 3000)
cd frontend && npm run dev

# موبایل
cd mobile
flutter pub get
flutter run
```
