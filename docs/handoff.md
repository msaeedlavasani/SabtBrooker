> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۲۹ (تکمیل عملیات کارشناسی و تخصیص بک‌اِند)  
> فاز فعلی: Phase 2 — پیاده‌سازی Frontend (۹۰٪)  
> پیشرفت کلی: ~۸۵٪

---

## ۱. خلاصه اقدامات انجام شده (پنل کارشناس)

در این مرحله، چرخه «سرویس نقشه» با اضافه شدن قابلیت‌های کارشناسی کامل شد:

### ✅ بک‌اِند (Backend)
- **تخصیص کارشناس**: متد `AssignExpert` به `MapService` و `MapRepository` اضافه شد تا شناسه کارشناس را روی پرونده ثبت و وضعیت را به `expert_assigned` تغییر دهد.
- **Endpoint جدید**: آدرس `POST /v1/map-services/:id/accept` برای پذیرش پرونده توسط کارشناس پیاده‌سازی شد.
- **رفع تداخل تایپ**: مشکل `undefined: storage.MinIOStorage` با اصلاح نام به `FileStorage` برطرف شد.

### ✅ فرانت‌اِند (Frontend)
- **عملیات پذیرش**: دکمه «قبول پرونده» در داشبورد کارشناس به بک‌اِند متصل شد.
- **جزئیات کارشناسی (`/expert/cases/[id]`)**: 
    - طراحی صفحه مدیریت پرونده برای کارشناس.
    - قابلیت شروع عملیات میدانی (`fieldwork_start`).
    - دکمه تایید نهایی و ارسال به سازمان ثبت پس از تکمیل مدارک.
- **بهبود روتینگ**: سیستم تشخیص نقش (Role-based) در صفحه لاگین نهایی شد.

---

## ۲. ساختار مسیرها (Frontend)
- `/`: ورود (OTP)
- `/dashboard`: پنل متقاضی
- `/expert/dashboard`: داشبورد کارشناس (لیست پرونده‌های جدید و فعال)
- `/expert/cases/[id]`: پنل عملیاتی کارشناس برای تایید نقشه

---

## ۳. تسک‌های باقی‌مانده (شروع مرحله بعد)

| اولویت | کار | توضیح |
|---|---|---|
| 🔴 ۱ | **درج ادعا (Claim)** | فرم بارگذاری اسناد مالکیت (مبایعه‌نامه، صلح‌نامه و ...) در فرانت‌اِند |
| 🔴 ۲ | **AI Advisor** | نمایش راهنمایی‌های هوشمند ثبتی در پنل ادعا |
| 🟡 ۳ | **سرویس گواهی** | پیاده‌سازی فاز نهایی زنجیره (درج گواهی اقدام) |

## ۴. دستور اجرای سریع
```bash
docker-compose up -d
cd backend && go run cmd/server/main.go # Port 8081
cd frontend && npm run dev             # Port 3000
```
