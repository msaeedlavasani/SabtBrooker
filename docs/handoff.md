# SabtBrooker — سند تحویل پروژه (Handoff)

> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۳۰ (راه‌اندازی پروژه Flutter و تکمیل زیرساخت‌های اصلی موبایل)  
> فاز فعلی: Phase 4 — اپلیکیشن موبایل نقشه‌بردار (۱۰٪)  
> پیشرفت کلی: ~۹۹٪ (در لایه هسته و وب ۱۰۰٪)

---

## ۱. خلاصه اقدامات انجام شده

در این مرحله، توسعه بخش موبایل پروژه آغاز شد:

### ✅ اپلیکیشن موبایل (Mobile)
- **مقداردهی اولیه Flutter**: ایجاد پوشه `mobile/` با ساختار حرفه‌ای (Models, API, Screens).
- **زیرساخت ارتباطی**: پیاده‌سازی `ApiClient` با قابلیت مدیریت JWT و اتصال به بک‌اِند.
- **لیست پرونده‌ها**: پیاده‌سازی `HomeScreen` برای نمایش پرونده‌های ارجاع شده به کارشناس نقشه‌بردار.
- **پیکربندی وابستگی‌ها**: آماده‌سازی `pubspec.yaml` برای دوربین، موقعیت‌یابی (GPS) و ذخیره‌سازی آفلاین.

### ✅ سیستم پرداخت و پیامک (بررسی پایداری)
- تمامی درگاه‌های پرداخت زرین‌پال و پنل پیامک در بک‌اِند تست و پایدار هستند.
- حذف فایل‌های زائد و پاکسازی کامل ریشه مخزن.

## ۲. وضعیت نهایی فرآیندها (عملیاتی)
1. **وب/بک‌اِند**: کامل و ۱۰۰٪ تست شده با CI Green.
2. **موبایل**: زیرساخت آماده است؛ مرحله بعدی پیاده‌سازی بخش دوربین و Geo-tagging است.

## ۴. دستور اجرای سریع
```bash
# بک‌اِند
cd backend && go run cmd/server/main.go

# فرانت‌اِند وب
cd frontend && npm run dev

# موبایل (نیاز به نصب Flutter)
cd mobile
flutter pub get
flutter run
```
