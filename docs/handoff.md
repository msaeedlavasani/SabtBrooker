# SabtBrooker — سند تحویل پروژه (Handoff)

> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۳۰ (تکمیل فرانت‌اِند منطبق با دمو و بهینه‌سازی ویزاردها)  
> فاز فعلی: Phase 2 — پیاده‌سازی Frontend (۱۰۰٪)  
> پیشرفت کلی: ~۹۵٪

---

## ۱. خلاصه اقدامات انجام شده (فرانت‌اِند حرفه‌ای و یکپارچه‌سازی)

در این مرحله، فرانت‌اِند پروژه از یک نسخه اولیه به یک اپلیکیشن حرفه‌ای و پویا تبدیل شد:

### ✅ فرانت‌اِند (Frontend)
- **انطباق کامل با دمو**: تمامی فیلدها، منطق‌های شرطی و استایل‌های موجود در `docs/demo-reference.html` به کامپوننت‌های React منتقل شد.
- **FormWizard هوشمند**: ایجاد کامپوننت `FormWizard` برای مدیریت خودکار:
    - نمایش شرطی فیلدها بر اساس نقش کاربر (اصیل/نماینده) یا نوع ملک.
    - اعتبارسنجی پیشرفته (Validation).
    - مدیریت فیلدهای تکرارشونده (مانند اسناد مالکیت و اشخاص ثالث).
    - هندلینگ OTP و رضایت‌نامه‌های دیجیتال.
- **پنل مدیریت پرونده پویا**: صفحه جزئیات پرونده (`/dashboard/cases/[id]`) بازنویسی شد تا بر اساس وضعیت فعلی پرونده در بک‌اِند، مراحل مربوطه (نقشه‌برداری، ادعا، گواهی) را به صورت خودکار فعال کند.
- **بهبود UI/UX**: پیاده‌سازی Progress Tracker دقیق و بخش تاریخچه فعالیت‌ها.

### ✅ بک‌اِند (Backend)
- **رفع باگ API**: مشکل ناهماهنگی نام فیلد `capacity` در ایجاد پرونده برطرف شد (اصلاح به `applicant_capacity`).
- **پیکربندی جریان کاری**: آماده‌سازی ساختارهای داده برای دریافت اطلاعات تفصیلی نقشه و ادعا.

---

## ۲. وضعیت فعلی فرآیندها
1. **پیش‌نویس**: تکمیل اطلاعات هویتی و مکانی متقاضی.
2. **نقشه‌برداری**: تخصیص کارشناس، بازدید میدانی و ثبت اطلاعات فنی (DWG/JSON).
3. **درج ادعا**: بارگذاری اسناد مالکیت، تعیین سهم و مشاور هوش مصنوعی.
4. **گواهی اقدام**: صدور سند نهایی زنجیره.

## ۴. دستور اجرای سریع
```bash
docker-compose up -d
cd backend && go run cmd/server/main.go # Port 8081
cd frontend && npm run dev             # Port 3000
```
