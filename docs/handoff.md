# SabtBrooker — سند تحویل پروژه (Handoff)

> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۲۹ (پایان جلسه - پیاده‌سازی کامل هسته فرانت‌اِند)  
> فاز فعلی: Phase 2 — پیاده‌سازی Frontend (۸۰٪)  
> پیشرفت کلی: ~۷۵٪

---

## ۱. خلاصه اقدامات جلسه امروز

امروز پروژه از محیط سرور به محیط محلی (مک) منتقل شد و بخش‌های زیر با موفقیت پیاده‌سازی و در GitHub ثبت شدند:

### ✅ بک‌اِند (Backend)
- **انتقال و رفع باگ**: تمامی کدهای فاز ۱ (Repository, Service, Handler) بازسازی و خطاهای کامپایل رفع شد.
- **تغییر پورت**: به دلیل تداخل با AirPlay مک، پورت پیش‌فرض از 8080 به **8081** تغییر یافت.
- **Storage**: سیستم ذخیره‌سازی MinIO فعال شد و هندلر جدید برای صدور **Presigned URL** جهت آپلود مستقیم پیاده‌سازی شد.

### ✅ فرانت‌اِند (Frontend)
- **پروژه Next.js**: راه‌اندازی با TypeScript، Tailwind CSS و فونت Vazirmatn.
- **احراز هویت**: پیاده‌سازی کامل جریان **OTP** (ارسال و تایید) و مدیریت JWT در LocalStorage.
- **مدیریت پرونده**: 
    - فرم ۳ مرحله‌ای تشکیل پرونده جدید.
    - صفحه جزئیات پرونده با قابلیت رهگیری وضعیت پیشرفت.
- **آپلود فایل**: ساخت کامپوننت `FileUpload` متصل به S3 برای بارگذاری مدارک نقشه.
- **پنل کارشناس**: ایجاد داشبورد اختصاصی برای نقش `expert` و پیاده‌سازی منطق روتینگ نقش‌محور.

---

## ۲. ساختار پروژه و وضعیت فایل‌ها

### مسیرهای مهم فرانت‌اِند:
- `/`: ورود با شماره همراه.
- `/dashboard`: پنل متقاضی (مشاهده پرونده‌ها).
- `/dashboard/new-case`: فرم تشکیل پرونده.
- `/dashboard/cases/[id]`: مدیریت پرونده و آپلود مدارک نقشه.
- `/expert/dashboard`: داشبورد اختصاصی کارشناسان ثبت.

## ۳. دستورات اجرا (محیط محلی)

```bash
# ۱. اجرای زیرساخت (دیتابیس، ردیس، مین‌آیو)
docker-compose up -d

# ۲. اجرای بک‌اِند (پورت ۸۰۸۱)
cd backend && go run cmd/server/main.go

# ۳. اجرای فرانت‌اِند (پورت ۳۰۰۰)
cd frontend && npm run dev
```

## ۵. نکات فنی برای توسعه‌دهنده بعدی
- **نسخه Go**: ۱.۲۵ یا بالاتر (مطابق با `go.mod`).
- **MinIO**: برای تست آپلود باید کانتینر MinIO حتماً اجرا شده باشد.
- **Role**: نقش کاربر در پاسخ API `/v1/auth/me` مشخص می‌شود و بر اساس آن کاربر به داشبورد مربوطه هدایت می‌گردد.
- **Docker**: فایل `docker-compose.yml` برای پورت ۸۰۸۱ به‌روزرسانی شده است.
