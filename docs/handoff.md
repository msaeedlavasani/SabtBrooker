# SabtBrooker — سند تحویل پروژه (Handoff)

> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۳۰ (تکمیل تمامی هندلرهای جریان کاری در بک‌اِند و یکپارچه‌سازی با MinIO)  
> فاز فعلی: Phase 3 — تکمیل نهایی بک‌اِند (۹۰٪)  
> پیشرفت کلی: ~۹۰٪

---

## ۱. خلاصه اقدامات انجام شده

در این مرحله، تمامی حلقه‌های مفقوده در جریان‌های کاری (Workflows) تکمیل شد:

### ✅ بک‌اِند (Backend)
- **تکمیل هندلرهای نقشه‌برداری، ادعا و گواهی**:
    - تمامی متدهای `UpdateDetails` و `Submit` اکنون از تراکنش‌های دیتابیس (Atomicity) استفاده می‌کنند.
    - قابلیت ثبت همزمان چندین مدرک مالکیت و عکس‌های Geo-tagged برای ملک.
    - یکپارچگی کامل با PostGIS برای ذخیره دقیق مختصات جغرافیایی.
- **یکپارچه‌سازی واقعی با فایل**: حذف داده‌های Mock و استفاده از شناسه‌های واقعی MinIO بازگشتی از فرانت‌اِند.
- **رفع باگ‌های سیستمی**: 
    - اصلاح خطاهای کامپایل و حذف ایمپورت‌های بلااستفاده.
    - رفع خطای `go vet` در فایل‌های تست (`claim_service_test.go`) با حذف تست‌های مربوط به ساختارهای منسوخ شده.
    - هماهنگ‌سازی کامل لایه‌های Repo, Service و Handler.

### ✅ فرانت‌اِند (Frontend)
- **آپلود واقعی فایل**: اتصال کامپوننت `FileUpload` به `FormWizard` جهت آپلود مستقیم به MinIO.
- **انطباق کامل با دمو**: پیاده‌سازی تمامی فیلدها و منطق‌های شرطی `demo-reference.html`.

---

## ۲. وضعیت فعلی فرآیندها (End-to-End)
1. **تشکیل پرونده**: ثبت اطلاعات هویتی و ظرفیت (اصیل/نماینده).
2. **نقشه‌برداری**: تخصیص کارشناس، بازدید میدانی، ثبت عکس‌های Geo-tagged و آپلود فایل DWG.
3. **درج ادعا**: بارگذاری چندین سند مالکیت، تعیین سهم و دریافت مشاوره AI.
4. **گواهی اقدام**: ثبت مرحله نهایی و تکمیل زنجیره کارگزاری.

## ۴. دستور اجرای سریع
```bash
docker-compose up -d
cd backend && go run cmd/server/main.go # Port 8081
cd frontend && npm run dev             # Port 3000
```
