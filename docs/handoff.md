# SabtBrooker — سند تحویل پروژه

> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۲۹ (پایان جلسه - تکمیل پنل کارشناس و زیرساخت فرانت‌اِند)  
> فاز فعلی: Phase 2 — پیاده‌سازی Frontend (۸۰٪)  
> پیشرفت کلی: ~۷۵٪

---

## وضعیت نهایی جلسه امروز

### ✅ دستاوردهای اصلی:
۱.  **بازسازی کامل فاز ۱**: انتقال تمام کدها از سرور به مک و رفع خطاهای کامپایل.
۲.  **راه‌اندازی فرانت‌اِند**: ایجاد پروژه Next.js با Tailwind و فونت فارسی.
۳.  **سیستم احراز هویت**: پیاده‌سازی کامل جریان OTP و مدیریت توکن در فرانت‌اِند.
۴.  **مدیریت پرونده**: قابلیت تشکیل پرونده و مشاهده چرخه حیات آن در UI.
۵.  **سیستم ذخیره‌سازی**: اتصال به MinIO و پیاده‌سازی کامپوننت آپلود فایل.
۶.  **پنل کارشناس**: تفکیک نقش‌های کاربری و ایجاد داشبورد اختصاصی برای کارشناسان ثبت.

---

## ساختار مسیرها (Frontend)
- `/`: صفحه ورود (OTP)
- `/dashboard`: پنل متقاضی
- `/dashboard/new-case`: فرم تشکیل پرونده
- `/dashboard/cases/[id]`: جزئیات پرونده و مدیریت نقشه
- `/expert/dashboard`: پنل اختصاصی کارشناس

---

## تسک‌های اولویت‌دار برای شروع جلسه بعد
- [ ] **عملیات کارشناس**: افزودن قابلیت "پذیرش پرونده" و "تایید نهایی نقشه" در پنل کارشناس.
- [ ] **درج ادعا (Claim)**: پیاده‌سازی فرم بارگذاری مستندات مالکیت در پنل متقاضی.
- [ ] **AI Advisor**: اتصال بخش راهنمایی هوش مصنوعی به UI.

---

## دستور اجرای سریع
```bash
docker-compose up -d
cd backend && go run cmd/server/main.go # (Port 8081)
cd frontend && npm run dev             # (Port 3000)
```
