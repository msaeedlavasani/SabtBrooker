# SabtBrooker — سند تحویل پروژه (Handoff)

> آخرین به‌روزرسانی: ۲۰۲۶-۰۷-۳۰ (یکپارچه‌سازی سیستم پیامک و تکمیل نهایی تمامی Workflows)  
> فاز فعلی: Phase 3 — تکمیل نهایی بک‌اِند (۹۸٪)  
> پیشرفت کلی: ~۹۸٪

---

## ۱. خلاصه اقدامات انجام شده

در این مرحله، پروژه به وضعیت عملیاتی کامل (End-to-End) رسید:

### ✅ بک‌اِند (Backend)
- **سیستم پیامک (SMS Integration)**:
    - پیاده‌سازی اینترفیس `SMSProvider` با دو درایور `Kavenegar` (عملیاتی) و `Console` (توسعه).
    - یکپارچه‌سازی سرویس OTP با سیستم پیامک؛ کد تایید اکنون به صورت واقعی ارسال می‌شود.
- **تکمیل Workflows**:
    - تمامی سرویس‌های نقشه، ادعا و گواهی اکنون از متدهای `UpdateDetails` تراکنشی استفاده می‌کنند.
    - قابلیت ثبت همزمان چندین مدرک مالکیت در جداول دیتابیس.
- **پایداری و تست**:
    - رفع تمامی خطاهای `go vet` در لایه سرویس و تست‌ها.
    - اصلاح ترتیب مقداردهی اولیه در `main.go` برای مدیریت صحیح وابستگی‌ها.

### ✅ فرانت‌اِند (Frontend)
- **آپلود واقعی فایل**: اتصال کامل به MinIO؛ شناسه‌های تستی حذف شدند.
- **ویزارد هوشمند**: تمامی مراحل مطابق دمو با قابلیت نمایش شرطی فیلدها فعال است.

---

## ۲. وضعیت فعلی فرآیندها (عملیاتی)
1. **احراز هویت**: ورود با شماره همراه + ارسال واقعی پیامک تایید.
2. **نقشه‌برداری**: ثبت عکس‌های Geo-tagged و آپلود فایل فنی (DWG).
3. **درج ادعا**: بارگذاری اسناد مالکیت و تعیین سهم (تراکنشی).
4. **گواهی اقدام**: اتمام زنجیره و صدور کد نهایی.

## ۴. دستور اجرای سریع
```bash
docker-compose up -d
cd backend && go run cmd/server/main.go # Port 8081
cd frontend && npm run dev             # Port 3000
```
