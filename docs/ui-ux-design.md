# UI/UX Design — طراحی تفصیلی
## سه Persona، یک گردش‌کار منسجم

> اصل راهنما: «کاربر نباید بداند پشت صحنه چه اتفاقی می‌افتد. فقط باید وضعیت خودش را بفهمد و قدم بعدی را بداند.»

## ۱. طراحی Stepper — عنصر مشترک هر سه Persona

### ۱.۱ Stepper Component (سه مرحله)

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                  │
│   ●━━━━━━━━━●━━━━━━━━━○━━━━━━━━━○                               │
│   نقشه ثبتی   درج ادعا   گواهی اقدام   تکمیل                     │
│   (فعال)     (غیرفعال)  (غیرفعال)                                │
│                                                                  │
│   ═══════════════════════════════════════════════════            │
│   وضعیت فعلی: در انتظار تایید سازمان                              │
│   کد رهگیری نقشه: MP-14030815-XXXX                               │
│   ═══════════════════════════════════════════════════            │
│                                                                  │
│   کارهای شما:                                                     │
│   ○ منتظر پاسخ سازمان باشید (معمولاً ۲۴-۴۸ ساعت)                  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

**حالت‌های Stepper:**

| وضعیت پرونده | نمایش Stepper |
|---|---|
| `draft` | فقط «نقشه ثبتی» با حالت «در انتظار شروع» |
| `map_in_progress` | مرحله ۱ فعال (نارنجی)، بقیه خاکستری |
| `map_completed` | مرحله ۱ تیک سبز، مرحله ۲ با حالت «آماده شروع» |
| `claim_in_progress` | مرحله ۱ تیک سبز، مرحله ۲ فعال (نارنجی) |
| `claim_completed` | مراحل ۱ و ۲ تیک سبز، مرحله ۳ «آماده شروع» |
| `cert_in_progress` | مراحل ۱ و ۲ تیک سبز، مرحله ۳ فعال (نارنجی) |
| `cert_completed` | هر سه مرحله تیک سبز + «تکمیل شد» |
| `expired` | مرحله آخر با ضربدر قرمز + پیام مهلت |
| `rejected` | مرحله جاری با ضربدر قرمز + دلیل rejection |

**قابلیت‌های اپ موبایل:**

| قابلیت | شرح |
|---|---|
| **آفلاین** | ذخیره اطلاعات ماموریت روی دستگاه — همگام‌سازی خودکار هنگام اتصال |
| **GPS Auto-tag** | هنگام عکس‌برداری، مختصات و زمان به‌طور خودکار در EXIF درج می‌شود |

## ۷. اصول UX کلیدی

| اصل | توضیح |
|---|---|
| **عدم غافلگیری** | هر transition وضعیت با نوتیفیکیشن (پیامک + in-app) همراه است |
| **Timeout آگاه‌سازی** | مهلت‌های قانونی به صورت countdown نمایش داده شوند (مثلاً «۱۸ ماه تا پایان مهلت») |
| **خطای فارسی** | تمام خطاها به فارسی روان — بدون stack trace یا error code فنی |
| **تأیید قبل از عمل خطرناک** | «انصراف از پرونده» و «رد مستندات» حتماً confirm دیالوگ دارند |
| **Offline-first (موبایل)** | کارشناس نقشه‌بردار در مناطق بدون اینترنت هم باید بتواند کار کند |
| **Accessibility** | WCAG 2.1 AA — فونت خوانا (IRANSans 16px)، contrast ratio ≥ 4.5:1 |
